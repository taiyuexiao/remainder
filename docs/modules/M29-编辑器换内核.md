# M29 文档编辑器换内核（feishu-docs-clone 对齐）

> 方案：`docs/research/feishu-clone对齐方案.md`（调研+可行性）。
> 路线：整体移植 feishu-docs-clone 编辑器（29 文件 ~4400 行）为 remainder 文档新内核，remainder 独有功能回植。

## 实现

### 换内核（S1+S2）

- **依赖**：补 `extension-underline/text-align/code-block-lowlight@2.27.3/lowlight/highlight.js/katex/heading/bold/italic/strike/code`（双方同为 Tiptap 2.11.x，零适配）
- **`desktop/src/editor2/`**：feishu-clone `src/editor/*` + `icons.tsx` + `EditorPage.tsx` 整体搬入；`fe.css`（4006 行 .fe-* 前缀）剥掉全局 reset 后与 Tailwind 共存
- **`editor2/store.ts`**（自写适配层）：同 API 面换后端——文档内容/标题走 remainder server documents API（`primeDoc` 预灌同步缓存），starred/图标/封面/宽度/快照/划线评论走 localStorage
- **`EditorShell.tsx`**：primeDoc → 渲染 EditorPage；文档副本 fe-doc-created 事件跳真 id
- **AI 改走 server 代理**：新增 `POST /api/llm/chat-stream`（DeepSeek SSE 透传，key 不出 server），`ai/config.ts` 的 streamChat 指向它

### 回植 remainder 独有（S3）

- **字体/字号**：FontSizeAttr + FontFamily 注册进新内核（老文档字号属性不丢），常驻工具栏加两个下拉
- **错别字批处理**：`TypoCheck.tsx`（M18 逻辑移植，流式纠错开关未回植）
- **表格识别双通道**：粘贴 Tab/空格/管道文本自动转表（editorProps 注入 PmDOMParser slice）+ 浮条 ⇥ 选中表格化
- **导出 Markdown**：更多菜单 → 走 server `/api/documents/:id/export`
- AI 三件套（✨询问/AI 排版）由新内核的 AI 侧栏 + 一键排版覆盖（走 server 代理）

### 切换与清理（S4+S5）

- DocsPage 编辑区 → EditorShell；删除旧 `editor/` 8 文件（仅留 treeDragStore）与 DocsPage 内 600 行旧编辑器代码

### 新增能力（feishu-clone 带来）

常驻 40px 工具栏（22 按钮）、H1-H9 渐进、下划线/对齐、KaTeX 公式、Callout、分栏、代码块语法高亮、查找替换⌘F、版本快照、划线评论、中文 Markdown 即时转换、md 粘贴成块、@提及、阅读/编辑模式、飞书全套 UI 数值（800px/16px/1.7/40px 标题/#3370FF）

## 报错及解决方案

| 报错 | 原因 | 解决 |
|---|---|---|
| **数据事故：2 个真实文档被清空** | 剪藏转换的文档内容是 HTML 非 JSON；新内核 `parseStoredContent` JSON.parse 失败回退空文档，EditorPage 卸载时无条件 doSave 把空文档写回 | ① parseStoredContent 非 JSON 原样交 Tiptap 解析 ② doSave 加脏标记（未编辑不落盘）③ Figma 文档从 clips.content_html 完整恢复；「工程方法」WAL 取证失败（已 checkpoint），向用户如实报告 |
| 正文宽度实测 688 ≠ 800 | 容器双栏挤压，max-width 800 是上限非定宽 | 断言改 computed maxWidth |
| 编辑内容 PATCH 到错误文档 | e2e clickByText 命中容器 div，误开其他文档（AGENTS.md #15 同类） | 精确匹配标题 span + 可信点击（树行用 mousedown/mouseup 选中，el.click() 合成事件无效） |
| tsc 找不到 extension-heading/bold 等 | feishu-clone 显式 import 了 StarterKit 内包子包 | 补装 5 个 @tiptap/extension-* |
| Toolbar 加下拉时 Bold 按钮被吞 | StrReplaceFile old 串末尾带下一行开头，新串漏带 |  grep 验证后补回（老毛病，已三犯） |
