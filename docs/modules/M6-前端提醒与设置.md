# M6 前端提醒轮询 + 设置页 + 今日页

## 1. 任务背景
M6 后端已完成定时器、通知队列、邮件日报、LLM 总结。Windows 系统通知弹窗需要 Tauri（待装 VS Build Tools），但浏览器内可先实现 Toast 提醒、设置页与今日视图页，让 v1 在浏览器环境已具备完整提醒闭环。

## 2. 目标
- 前端每 30s 轮询 `/api/notifications`，有新提醒时右上角 Toast 弹出，随后清空后端队列
- 设置页可开关提醒通知、LLM 日报总结，可配置日报时间与接收邮箱
- 今日页展示四段数据（逾期/今日到期/今日待跟进/今日已完成）

## 3. 需求
- Toast 显示任务标题，8s 自动消失，可手动关闭
- 设置项写入 `/api/settings`，布尔项用开关、文本项失焦保存
- 今日页复用 `/api/tasks/today` 聚合接口

## 4. 产出
- `desktop/src/pages/TodayPage.tsx`
- `desktop/src/pages/SettingsPage.tsx`
- `desktop/src/App.tsx`：Toast 容器 + 30s 轮询 + 页面路由接入
- `desktop/src/api/client.ts`：NotificationItem 类型与通知 API

## 5. 实现方案
App 挂载时启动轮询；`listNotifications` 返回后把新通知追加到 toasts，并调用 `clearNotifications` 防止重复弹。设置页布尔开关直接写 `true/false` 字符串到 settings 表。
