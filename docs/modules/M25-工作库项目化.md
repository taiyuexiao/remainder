# M25 工作库项目化（K2）

> 方案：`docs/research/团队知识共享平台方案v3-团队模式.md` §2.1。
> 工作库从平铺条目改为 **项目 → 子项目 → 条目** 三层树；新建项目可 @负责人；@人触发 P0 必达通知。

## 实现

### 服务端

- **v13 迁移**（`db/schema.ts`）：
  - `kb_projects`（id/team_id/name/description/parent_id 自嵌套/owners JSON/status/sort_order/时间戳）
  - `knowledge_items` 加 `project_id`（可空=未分配）
  - 与任务模块的 `projects` 表无关（那是任务项目）；知识库自己的项目树，按 `team_id` 隔离
- **`routes/kbProjects.ts`**：项目 CRUD
  - `GET /api/kb-projects?team=` 平铺返回（客户端组树），带 item_count
  - POST 新建（parent_id 校验同团队 + 防环，沿父链最多查 10 层）
  - PATCH 重命名/简介/owners/移动/归档
  - DELETE 守卫：有子项目或条目时拒绝
- **`routes/knowledge.ts`**：条目加 `project_id`（新建/更新均校验同团队项目）；列表加 `project` 过滤参数（`none`=未分配）
- **@人 P0 必达**：`scheduler/index.ts` 新增 `pushNotification(title, refId)`；knowledge 条目和 kb_projects 的 owners 新增非作者名字时推通知（桌面端轮询 `/api/notifications` 弹 toast）
- **个人空间成员合成**：`GET /api/teams/personal` 无成员记录时返回「我」，让 @负责人 选择器在单机也可用

### 桌面端

- **`WorkLibraryPanel.tsx`**（新）：二级菜单选「📐 工作库」时的面板
  - 左：项目树（📁 项目 / 📂 子项目，展开收起、item_count、@负责人 chips；hover 行内 ＋子项目/✎编辑/🗑删除）
  - 右：复用 KnowledgePanel 按项目过滤；「全部条目」「🗂 未分配」两个虚拟节点
  - 项目表单弹窗：名称/简介/@负责人 chips（团队成员多选）
- **`KnowledgePanel.tsx`**：新增 `projectId`（undefined 不过滤 / null 未分配 / id）+ `projects` + `members` props
  - 新建弹窗：**类型按钮只显示当前层的类型**（工作库=规范/契约/决策，防"建错类型不可见"）+ 项目下拉 + @负责人 chips
  - 详情侧栏元信息行显示 @owners

## 报错及解决方案

| 报错 | 原因 | 解决 |
|---|---|---|
| e2e 建条目后面板不显示「接口契约 v3」 | 工作库层只列 guide/spec/adr，而新建弹窗类型默认 note | 新建弹窗类型按钮限定为当前层类型，默认取 `currentTypes[0]` |
| e2e 等不到「@负责人」选择器 | personal 团队无成员记录，members=[] → chips 不渲染 | server 端 personal 合成当前用户为成员 |
| PowerShell 清理测试数据失败 | curl.exe 输出 GBK 字节流，`ConvertFrom-Json` 解析含中文 JSON 报错 | 中文 JSON 一律用 node fetch 脚本处理（已记入 AGENTS.md 教训 #11） |
