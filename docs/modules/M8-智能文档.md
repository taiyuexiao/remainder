# M8 智能文档（Tiptap）

## 1. 任务背景
PRD v2「知识沉淀」阶段的核心模块：类飞书的智能文档编辑器，用于沉淀周报/总结/笔记，也是 Inbox 条目「沉淀到文档」的落点。依赖前置：M1.2 建表（`documents` 表已在 schema 中）、M2.2 主窗口导航（`docs` 占位页）。

## 2. 目标
- 后端 documents REST CRUD 全通（list/get/create/patch/delete），`content` 存 Tiptap JSON（TEXT）
- 前端文档页：左侧文档列表 + 右侧 Tiptap 编辑器，固定顶部工具栏，标题可编辑，内容 1s 防抖自动保存

## 3. 需求
- API：`GET /api/documents`（按 updated_at 倒序）、`GET /:id`、`POST`（body: title 必填，content 可选，缺省为空 tiptap doc）、`PATCH /:id`（title?/content?，自动刷 updated_at）、`DELETE /:id`；404/400 语义正确
- 编辑器块/格式：H1-H3、段落、加粗/斜体、无序/有序列表、任务列表（checkbox）、引用、代码块、分割线、表格（插入 3x3 + 行列追加）、图片（URL 输入 + 粘贴图片自动转 base64 data URL）
- 交互：固定顶部工具栏（飞书/Notion 风格）；slash 菜单不做（backlog）
- 自动保存：标题与内容变更 1s 防抖 PATCH；底栏显示最后保存时间与保存状态
- 不做文件服务器：图片仅 URL 或 base64 内联

## 4. 产出
- `server/src/routes/documents.ts`：documents CRUD 路由（注册于 `server/src/index.ts`）
- `server/verify-m8.ps1`：CRUD 端到端验证脚本（ASCII）
- `desktop/src/pages/DocsPage.tsx`：文档列表 + DocEditor + Toolbar
- `desktop/src/api/client.ts`：`Document` / `DocumentInput` 类型 + `api.listDocuments/getDocument/createDocument/updateDocument/deleteDocument`
- `desktop/src/App.tsx`：`docs` 导航从占位页替换为真实 `DocsPage`
- `desktop/src/index.css`：`.ProseMirror` 编辑器排版样式（标题/列表/任务列表/引用/代码块/表格/图片/placeholder）

## 5. 实现方案
- 后端：复用 `helpers.ts` 的 `now()/uuid()`，better-sqlite3 同步 SQL；PATCH 动态拼 SET 子句，仅更新传入字段
- 前端：Tiptap v2 React。扩展 = StarterKit（内置 heading/列表/引用/代码块/分割线，heading 限 1-3 级）+ TaskList/TaskItem(nested) + Table 四件套 + Image + Placeholder
- 粘贴 base64：`editorProps.handlePaste` 拦截 `clipboardData.items` 中的 `image/*`，FileReader 转 data URL 后 `setImage` 内联
- 自动保存：`editor.on('update')` → `getJSON()` → 1s 防抖 PATCH；切换文档用 `key={doc.id}` 重建编辑器；保存成功后刷新列表更新 updated_at
- 表格：简化为「插入 3x3 表格」按钮，光标在表格内时额外出现「行+」「列+」按钮

## 6. 遇到的报错及解决方案
| 报错/问题 | 原因 | 解决方案 |
|-----------|------|----------|
| HorizontalRule 重复扩展告警 | Tiptap v2 StarterKit 已内置 horizontalRule，又单独注册同名扩展 | 移除独立 `@tiptap/extension-horizontal-rule` 依赖，直接用 StarterKit 内置 |
| `prose` 排版类不生效 | 未安装 `@tailwindcss/typography` 插件 | 不引插件，改用 `index.css` 手写 `.ProseMirror` 样式（KISS） |
