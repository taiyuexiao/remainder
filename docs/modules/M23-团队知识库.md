# M23 团队知识库（方案 v2 之 K1 阶段）

## 1. 任务背景

依 `docs/research/团队知识共享平台方案v2-融合版.md` 的 K1 阶段落地：七类型知识条目 + 四层呈现 + 沉淀入口 + agent MCP 读取 + 联机能力。同时满足"应用联网/联机共享"的硬需求。开发遵循 SPEC.md / PLAN.md 流程。

## 2. 目标

1. 知识条目七类型（intel/share/note/rfc/guide/spec/adr）+ 完整 schema（author/owners/channels/tags/ttl/status/acl/notify/related/结论/有用数/来源关联）
2. 四层 UI：⚡快讯（TTL 沉底）/ 💬探讨（结论回填+一键沉淀为经验/决策）/ 📚经验（笔记+分享）/ 📐工作库（规范+契约+决策）
3. 剪藏箱/Inbox 一键沉淀
4. agent 通过 MCP stdio server 读知识库（kb_search/kb_get/kb_list_recent）
5. 联机：server 可 HOST=0.0.0.0 + TEAM_TOKEN 认证；desktop 设置页可配节点地址+token
6. 邮件日报加「今日知识库动态」节

## 3. 需求与实现

### server
- DB v11：`knowledge_items` 全 schema 表 + `knowledge_fts`（trigram，与 docs 搜索同构）
- `services/knowledgeSearch.ts`：searchKnowledge（q 全文 / type/channel/tag/status 过滤 / 过期隐藏；<3 字 LIKE 兜底；rebuild 全量）
- `routes/knowledge.ts`：CRUD + conclude（rfc 结论回填 + promoteTo note/adr 一键沉淀）+ useful +1
- TTL：按类型默认值（intel 14d / note 180d / guide 90d / rfc 14d，spec/adr/share 不过期），可显式覆盖；expired 默认隐藏，`includeExpired=1` 可见
- 联机：`config.host`（HOST env）+ `config.teamToken`（TEAM_TOKEN env）；非回环请求强制 `x-team-token` 校验，未配置 token 时 503 拒外部
- 日报：scheduler 的 buildReportHtml 加知识库动态节

### desktop
- `api/client.ts`：API base 改为 `VITE_API_BASE ?? localStorage('api-base') ?? 默认`；请求头自动带 `x-team-token`（localStorage）；+8 个知识库方法 + 类型/常量
- `pages/KnowledgePage.tsx`：四层 tab + 卡片流（类型徽标/频道/标签/有用数/沉底日期）+ 新建弹窗（类型选择/频道点选/标签/作者/来源）+ 详情侧栏（有用+1/rfс 结论回填+沉淀/删除）
- `pages/ClipsPage.tsx`：「📚 沉淀」（→经验）+「⚡ 快讯」按钮，自动带 source_url + source_clip_id
- `pages/InboxPage.tsx`：「沉淀到知识库」（速记 → 经验，沉淀后从 Inbox 删除）
- `pages/SettingsPage.tsx`：「联机共享」区块（节点地址 + token + 恢复单机）

### MCP server（server/mcp-server/）
- stdio 传输（@modelcontextprotocol/sdk），HTTP 读 Remainder API
- 三工具；kb_get 过 acl/TTL 检查；env：REMAINDER_API / REMAINDER_TOKEN
- README 含 Claude Code / Cursor 配置示例

## 6. 注意事项

- pnpm 的 workspace 不含 `server/mcp-server`（独立 npm install 隔离装依赖，避免污染主锁文件）
- 联机鉴权只对非回环请求生效（本机请求免校验，单机体验零变化）
- 桌面端改联机地址后需重启应用生效（README/设置页已注明）
- 本阶段未做：agent 草稿闭环、P0 规则引擎、git 镜像导出、kb_constraints/kb_who_knows（K2/K3）
