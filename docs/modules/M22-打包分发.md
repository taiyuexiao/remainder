# M22 便携包分发（Win 便携包 + Mac 适配 + CI 双平台流水线）

## 1. 任务背景

把 Remainder 打包成"别人下载即用"的形态；追问 Mac 能否使用后做跨平台适配。

## 2. 产物

### 2.1 Windows 便携包（已实测）

`dist-package/Remainder-portable-v0.1.0.zip`（82 MB），结构：

```
Remainder/
├── 启动Remainder.bat      # 双击启动（自动起后端+前端；已运行则唤出主窗口）
├── README.txt             # 使用说明
├── app/remainder.exe      # Tauri 桌面应用
├── node/node.exe          # 内置便携 Node 22（免装环境）
└── server/                # dist + 生产依赖（hoisted 平铺）+ Hiyori 模型
```

- 不含用户数据（db/.env/大模型包），初始干净状态，可放心分发
- 实测：解压 → bat → 便携 node 起后端（新库）→ 前端启动 ✓

### 2.2 Mac 适配（代码层，需 CI 出包）

| Windows 专属点 | 处理 |
|---|---|
| server 三处 `spawn('explorer')`（open-external / live2d open-folder / 文档导出打开目录） | 抽 `server/src/services/openPath.ts`：win→explorer / mac→open / linux→xdg-open |
| 桌面小组件嵌入桌面层（Win32 `desktop_layer`） | 原本就 `cfg(windows)` 隔离；新增 `cfg(not(windows))` 降级：widget 改 `alwaysOnTop` 置顶悬浮 + 右上定位 |
| bat 启动器 | `dist-package/start.sh`（curl 健康检查 + nohup 起 node + `open Remainder.app`） |

### 2.3 GitHub Actions 流水线

`.github/workflows/release.yml`：workflow_dispatch 或打 `v*` tag 触发，双 job：
- `build-windows`（windows-latest）：出 `Remainder-portable-win-x64.zip`
- `build-macos`（macos-latest，arm64）：`pnpm tauri build` 出 Remainder.app，出 `Remainder-portable-mac-arm64.zip`
- 均以 artifact 上传

## 3. 关键坑

1. **pnpm 符号链接布局不可拷贝**：`pnpm deploy` / 直接复制 node_modules 后，包内依赖间 symlink 断链（pdfjs-dist 找不到）→ 解法：`pnpm install --prod --config.node-linker=hoisted` 产出 npm 式平铺真实文件，任何机器可跑
2. **better-sqlite3 原生模块**：构建脚本默认被 pnpm 拦截 → `--config.dangerously-allow-all-builds=true`
3. **Compress-Archive 几千小文件超时** → 用内置 `tar -a -c -f` 压缩（分钟级→秒级）
4. CI 出 Mac 包必须有 macOS runner（Tauri 不支持交叉编译），且 Mac 用 WKWebView 免运行时（比 Windows 的 WebView2 还省事）

## 4. 验证记录

- Windows 便携包：解压 → 启动 bat → health ok / Hiyori 模型列表 ok / 前端启动 ok
- `pnpm --filter server build` 0 错误；`cargo check --release` 通过
- Mac 包未实测（本机无 Mac），依赖 CI 首跑验证

## 5. 发版方式

- 本地快速出 Win 包：`dist-package/` 下按 2.1 结构组装 + `tar -a -c -f` 压缩
- 双平台正式包：仓库推 GitHub 后，Actions 手动触发 workflow_dispatch（或 `git tag v0.1.0 && git push --tags`）
