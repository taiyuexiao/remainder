# M11.5 剪藏箱页面

## 1. 任务背景

M11.1 服务端剪藏管线（POST /api/clips → 解析入库）与 M11.2 浏览器扩展（右键同步）已就绪，剪藏数据只能走 API 查看。本功能点补桌面端「剪藏箱」页面：列表 + 预览 + 一键转文档 + 删除，是剪藏链路面向用户的出口。（M11.3 微信通道、M11.4 知识库升级为后续独立功能点。）

## 2. 目标

1. 左侧剪藏列表（标题/来源域名/excerpt/时间/source 徽章/状态徽章），右侧 HTML 预览（图片可显示）；
2. 「转为文档」「删除」操作可用，已转换的禁用重复转换；
3. 导航加「剪藏」入口（Inbox 与文档之间）；`pnpm --filter desktop build` 0 错误。

## 3. 需求

- client.ts：`Clip` 类型（列表行无 content_html）+ `api.listClips/getClip/deleteClip/convertClip`，导出 `API_BASE` 供图片路径拼接；
- ClipsPage：
  - 列表卡片：source 徽章（扩展=sky / 剪贴板=purple）、状态徽章（待整理 slate / 已转文档 emerald）、来源域名（url 取 hostname 去 www.）、excerpt 两行截断、创建时间；
  - 预览：`dangerouslySetInnerHTML` 渲染 content_html（服务端已 sanitize），渲染前把 `src="/api/clips/images/` 替换为 `${API_BASE}/api/clips/images/`；
  - 选中条目才拉详情（GET /api/clips/:id），列表保持轻行；
  - 转换：convertClip 后刷新，已转文档按钮禁用；删除：confirm 后删，若正选中则清空选中；
  - 空态文案指引两条剪藏入口（浏览器右键同步 / 热键剪贴板剪藏）；
- 预览排版样式 `.clip-preview` 复用 ProseMirror 风格（h1-h3/list/blockquote/pre/code/img/table/a）。

## 4. 产出

| 文件 | 说明 |
|------|------|
| `desktop/src/api/client.ts` | Clip 类型、4 个 clips API、导出 API_BASE |
| `desktop/src/pages/ClipsPage.tsx` | 剪藏箱页面（列表 + 预览 + 操作） |
| `desktop/src/index.css` | `.clip-preview` 排版样式 |
| `desktop/src/App.tsx` | 导航加「剪藏 📥」（inbox 与 docs 之间） |

## 5. 实现方案

- 布局沿用 TasksPage 双栏：左列表右详情，`flex` + `border-r`；
- 详情数据流：`selectedId` → `useEffect` 拉 `getClip`（带 cancelled 标志防竞态），列表行数据与详情分离（列表接口本来就不返回 content_html）；
- 图片地址：`withImageBase()` 用 `replaceAll` 把相对 src 拼上 API_BASE——只在渲染层做替换，不动库里数据（库保持相对路径，换部署地址无需迁移）；
- 安全：content_html 已由服务端 sanitize-html 白名单清洗（无 script/style/内联事件，a 强制 rel=noopener），前端直接渲染。
