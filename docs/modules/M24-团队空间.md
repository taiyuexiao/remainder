# M24 团队空间（多团队 + 权限隔离）

> 目标：多人协作为团队协作服务；一人可属多个团队，团队间知识资产完全隔离。
> UI 参考 WPS Comate 团队空间：主导航「👥 团队」入口 → 团队列表 → 选定团队后二级竖排菜单（快讯/探讨/经验/工作库/成员与设置）。

## 实现

### 服务端

- **v12 迁移**（`db/schema.ts`）：
  - `teams`（id/name/description/invite_token/created_by/created_at）
  - `team_members`（team_id+user_name 主键，role: owner/admin/member）
  - `knowledge_items` 加 `team_id NOT NULL DEFAULT 'personal'`，存量归入「个人空间」
  - 内置 `personal` 团队：节点上所有用户默认可读写（单机零配置）
- **`services/teams.ts`**：`currentUser`（解析 `x-user-name` 头，客户端对中文名 encodeURIComponent，服务端 decode）、`roleOf/isMember/isAdmin/teamExists`
- **`routes/teams.ts`**：
  - `GET /api/teams` 我可见的团队（personal + 我加入的）
  - `POST /api/teams` 创建（创建者=owner，自动生成 8 位去混淆字符邀请码）
  - `POST /api/teams/join` 凭邀请码加入（member）
  - `GET /api/teams/:id` 详情+成员（邀请码仅 admin+ 可见）
  - `PATCH /api/teams/:id` 重命名/简介（admin+）
  - `POST/PATCH/DELETE /api/teams/:id/members[...]` 成员管理（admin+；owner 不可降级/移除；可自行退团）
  - `POST /api/teams/:id/rotate-invite` 重生成邀请码（旧码立即失效）
  - `DELETE /api/teams/:id` 仅 owner，且团队知识条目须为空
- **`routes/knowledge.ts`**：所有读/写按 `team_id` 过滤并校验成员身份；`team` 查询参数缺省=personal；新建条目 author 缺省=当前用户
- **身份模型**：LAN 信任制——客户端自报 `x-user-name`，同名即同人（文档明示，不外网暴露）
- **CORS**（`index.ts`）：`allowedHeaders` 增加 `x-user-name`
- **MCP**（`mcp-server/index.mjs`）：新增 `REMAINDER_USER`/`REMAINDER_TEAM` 环境变量；`kb_search`/`kb_list_recent` 加 `team` 参数

### 桌面端

- **主导航**：「📚 知识库」→「👥 团队」
- **`TeamsPage.tsx`**（新）：三栏布局
  - 栏1：团队列表（色块头像+名字+我的角色+条目数）+「＋新建团队」「🔑 凭邀请码加入」
  - 栏2：选定团队后的竖排菜单：⚡快讯 💬探讨 📚经验 📐工作库 ｜ 👤成员与设置
  - 栏3：`KnowledgePanel`（知识内容）或成员管理面板
  - 成员面板：成员列表/角色调整/移除/按名添加、邀请码复制/重生成、团队设置（重命名/删除）
- **`KnowledgePanel.tsx`**（新，替代原 `KnowledgePage.tsx`）：四层内容面板，props=team+layer；层切换从横排 tab 上移到栏2 菜单；新建条目自动带 `team_id`
- **`client.ts`**：所有请求带 `x-user-name: encodeURIComponent(名字)`（localStorage `user-name`）；新增团队 API 全套
- **设置页**：联机共享区新增「我的名字」字段

## 报错及解决方案

| 报错 | 原因 | 解决 |
|---|---|---|
| 浏览器 e2e 卡在启动页、无任何请求失败事件 | 中文「小武」直接塞进 `x-user-name` 头，HTTP 头仅允许 Latin-1，fetch 在发送前同步抛错 | 客户端 `encodeURIComponent`，服务端 `decodeURIComponent`（try/catch 回落原样） |
| CORS 拦截 `x-user-name` | `allowedHeaders` 未声明 | 加入 `allowedHeaders` |
| `npm init -y` 报 Invalid name ".tmp-e2e" | npm 包名不允许前导点 | 手写 `package.json`（name=tmp-e2e） |
| 重启应用后「团队加载失败：Not Found」 | 旧版 server 孤儿进程（管理员权限启动的）占着 3210，bat 起的新 server 绑定失败退出，前端健康检查连上的是旧进程 | 先查 `curl 127.0.0.1:3210/api/teams` 确认路由存在；杀掉旧 node 进程后用最新 dist 重启。**教训：改了没生效先怀疑端口被旧进程占** |
