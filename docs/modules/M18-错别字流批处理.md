# M18 错别字：流处理 + 批处理

## 1. 任务背景

写文档常见错别字，手动挑错打断心流。平台直接提供两条 LLM 纠错通道：**流处理**（边写边扫，发现即改，权限收紧为仅错别字）+ **批处理**（写完一键全文检查，先弹窗展示问题清单再决定应用）。

## 2. 目标

1. 打字停顿 2.5s 自动扫描当前段落，只修错别字，不打断写作、不改其他内容
2. 工具栏一键全文检查，弹窗列出「错误词 → 正确词 + 上下文」，可勾选/全部应用

## 3. 实现

### 3.1 server
- `fixTypos(text)`：严 prompt「只修同音/形近/多漏字，不动其他任何内容，无错返回原文」，temperature 0.1
- `checkTypos(text)`：要求输出 JSON 数组 `[{before, after, context}]`
- `POST /api/llm/typos`：`mode=fix` 返回修正文本；`mode=check` 稳健解析（去围栏/截取数组）返回 issues

### 3.2 流处理（DocEditor）
- 开关：工具栏「流式纠错」按钮，状态存 localStorage(`typo-stream`)，默认关
- `editor.on('update')` → 2.5s debounce → 只扫**光标所在顶层 paragraph**（代码块/表格/含图片段落跳过；<8 字跳过；同文重扫跳过）
- 竞态防护：序号比对（又打字则丢弃）+ 替换前校验段落文本未变
- 应用：首尾公共 diff，**只替换差异片段**（尽量保留段落内 marks）；失败静默

### 3.3 批处理（Toolbar 弹窗）
- 「错别字检查」→ `editor.getText()` 全文 → issues 弹窗
- 弹窗：每条 复选框 + ~~错误词~~（红划线）→ 正确词（绿）+ 上下文；底部 取消 / 应用选中 N / 全部应用
- 应用：逐条在文档 textblock 中先按 context 定位块、再替换 before→after（每修一条重新遍历，位置天然安全）

## 4. 产出

| 文件 | 说明 |
|------|------|
| `server/src/llm/index.ts` | +`fixTypos` / `checkTypos` |
| `server/src/routes/llm.ts` | +`POST /api/llm/typos` |
| `desktop/src/api/client.ts` | +`fixTypos` / `checkTypos` / `TypoIssue` |
| `desktop/src/pages/DocsPage.tsx` | 流处理 effect + 开关 + 批处理弹窗 |

## 5. 验证记录

- `mode=check` 真实 DeepSeek：4 个预埋错别字（按排/再接再励/准确虑/期侍）全部命中且 context 准确 ✓
- `mode=fix`：`今天按排的会议很成功` → `今天安排的会议很成功` ✓
- e2e 批处理：输入 2 个错别字 → 弹窗 2 条 → 全部应用 → 正文修正 ✓
- e2e 流处理：开开关 → 输入「这次按排非常合理」→ ~5s 后自动变为「这次安排非常合理」✓
- build 0 错误

## 6. 注意事项

- 流处理每次触发 = 一次 LLM 调用（DeepSeek 按量计费，量级为段落级，可接受；介费用就关掉开关）
- 修正片段会失去该处的行内样式（加粗等），这是 diff 替换的取舍
