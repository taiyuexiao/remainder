# M11.2 浏览器扩展（右键同步）

## 1. 任务背景
M11.1 服务端剪藏管线已就绪（POST /api/clips）。本功能点实现浏览器端入口：Chrome/Edge/Firefox 系浏览器里选中图文 → 右键 → 一键同步进剪藏箱。用户决策：开发者模式加载，不上架商店；通信走 localhost POST（不上 Native Messaging）。

## 2. 目标
- MV3 扩展，选中文字或图片时右键菜单出现「同步到 Remainder」
- 选区 HTML（含图片、懒加载 data-src、相对链接补全）POST 到本地服务
- 系统通知反馈成功/失败

## 3. 需求
- manifest MV3：contextMenus/activeTab/scripting/notifications 权限；host_permissions 覆盖 127.0.0.1:3210 与 localhost
- content.js：getSelection + cloneContents 取选区 HTML；img 懒加载属性回写 src；a/img 相对 URL 用 baseURI 补全
- background.js：右键菜单注册与点击处理；content script 取数失败时 selectionText 兜底；fetch 在 service worker 里发（绕页面 CORS）；chrome.notifications 反馈
- 服务端：OPTIONS 响应补 `Access-Control-Allow-Private-Network: true`（Chrome 130+ 私网访问预检）

## 4. 产出
- `clipper/manifest.json`、`clipper/background.js`、`clipper/content.js`、`clipper/icons/icon128.png`（复用桌面图标）、`clipper/README.md`（加载与使用说明）
- `server/src/index.ts`：onSend hook 对 OPTIONS 响应加 PNA 头

## 5. 实现方案
浏览器不允许外部程序改右键菜单 → MV3 contextMenus 是唯一正路。登录态天然无问题（content script 跑在用户会话里，还能绕过"禁止复制"站点限制）。CORS 此前已 `origin: true` 反射，扩展 origin（chrome-extension://<id>）直接放行。

## 6. 遇到的报错及解决方案
| 报错/问题 | 原因 | 解决方案 |
|-----------|------|----------|
| 子代理 LLM API 401（委派失败） | 子代理模型凭证临时失效 | M11.2 范围小，主线程直接实现 |
