# M14 文档编辑器：斜杠菜单 / 链接 / 表格识别

## 1. 任务背景

调研飞书云文档后对标其高效编辑交互：① 输入 "/" 弹出块类型菜单（飞书/Notion 行业标准）；② 文本挂链接并可跳转；③ 表格状文本自动识别转表格（API 文档/终端输出常见格式）。

## 2. 目标

1. 编辑器输入 "/"（行首或空格后，同飞书规则）弹菜单，支持过滤/键盘/鼠标操作
2. 选中文本可挂链接，Ctrl+点击链接系统浏览器打开；粘贴 URL 自动成链
3. 粘贴表格状纯文本自动转表格；也可选中文本后一键「排版为表格」

## 3. 需求与实现

### 3.1 斜杠菜单（desktop/src/editor/slashCommand.ts）
- 基于 `@tiptap/suggestion`：char='/'，默认匹配规则（空格后/行首触发，与飞书一致）
- 14 个条目：正文/标题1-3/待办/无序/有序列表/引用/代码块/分割线/表格/图片(填URL)/链接(填URL)/文本转表格
- 中文+拼音+英文关键字过滤；↑↓选择、Enter 执行、Esc 关闭、鼠标点击（onmousedown preventDefault 保焦点）
- 弹层为原生 DOM 类 `SlashPopup`（fixed 定位跟随光标，视口内防溢出）
- **关键坑**：Suggestion 配置必须提供顶层 `command({editor, range, props})` 回调，否则选中条目是 no-op（首版漏配导致回车无效，e2e 截图抓到"/bt"残留才发现）

### 3.2 链接
- `@tiptap/extension-link`：autolink + linkOnPaste；工具栏 🔗（弹窗填 URL，留空解除，预选当前 href）
- 跳转：`editorProps.handleClick` 拦截 Ctrl/Cmd+点击，取 link mark 的 href → `openExternalLink()`
- `openExternalLink`：Tauri 走 server `POST /api/open-external`（explorer 拉起默认浏览器，webview 的 window.open 不可靠），纯浏览器直接 window.open

### 3.3 表格识别（desktop/src/editor/tableDetect.ts）
- 三种格式：Markdown 管道 / Tab 分列（Excel）/ 2+ 空格对齐列（━━ 分隔线行自动忽略）
- 防误报：空格分列需 ≥3 行且 ≥60% 行能分出多列；散文/单行不识别
- **粘贴自动转**：handlePaste 里当剪贴板无 `<table>` HTML 时检测 text/plain，命中直接插入表格（比飞书实现简单但覆盖常见场景）
- **选中排版**：工具栏「⇥表格化」+ 斜杠菜单「文本转表格」，取选区文本解析替换

## 6. 注意事项

- 触发规则与飞书相同：'/' 必须出现在**行首或空格后**（紧跟文字不触发）
- e2e 曾污染真实文档：教训是 UI 测试一律用 API 建一次性文档、测完删除
- 飞书的高亮块（callout）因无对应块类型未实现，列入 backlog
