# M0.2 pnpm monorepo 脚手架

## 1. 任务背景
PRD/TECH 已确认（M0.1）。按计划项目采用 pnpm monorepo：`server/`（Fastify+TS 后端）+ `desktop/`（Tauri2+React+Vite+Tailwind 前端）。本功能点搭建可运行的最小骨架，为 M1/M2 提供地基。

## 2. 目标
- `pnpm dev:server` 可启动后端，`GET /api/health` 返回 ok
- `pnpm dev:desktop` 可启动 Vite dev server，页面可访问
- Tauri Rust 侧配置就绪（tauri.conf.json / Cargo.toml / capabilities）

## 3. 需求
- pnpm workspace 管理两个包；根 package.json 提供 dev:server / dev:desktop / dev:tauri 脚本
- server：Fastify + tsx watch + dotenv 配置（.env.example 含端口/163SMTP/DeepSeek 全部键）
- desktop：React 18 + TS + Tailwind v4（@tailwindcss/vite）+ Tauri 2（global-shortcut、notification 插件预装）；首页卡片显示后端健康状态（前后端联调预埋）
- .gitignore 覆盖 node_modules / .env / server/data / src-tauri/target

## 4. 产出
- 根：`package.json`、`pnpm-workspace.yaml`、`.gitignore`
- `server/`：`package.json`、`tsconfig.json`、`.env.example`、`src/config.ts`、`src/index.ts`（/api/health）
- `desktop/`：`package.json`、`vite.config.ts`、`tsconfig.json`、`index.html`、`src/main.tsx`、`src/App.tsx`、`src/index.css`
- `desktop/src-tauri/`：`tauri.conf.json`、`Cargo.toml`、`build.rs`、`src/main.rs`、`capabilities/default.json`

## 5. 实现方案
- Tailwind 用 v4 方案（vite 插件 + `@import "tailwindcss"`，零配置文件）
- Vite 端口 1420（Tauri 约定），前端通过 `VITE_API_BASE`（默认 http://127.0.0.1:3210）调后端
- Tauri 预注册 global-shortcut / notification 插件（M5/M6 直接用），capabilities 用 `windows: ["*"]` 覆盖未来多窗口

## 6. 遇到的报错及解决方案
| 报错/问题 | 原因 | 解决方案 |
|-----------|------|----------|
| `ERR_PNPM_IGNORED_BUILDS`（better-sqlite3、esbuild 构建脚本被拦截） | pnpm 11 默认不执行依赖的 postinstall | pnpm-workspace.yaml 加 `onlyBuiltDependencies` 白名单，再 `pnpm rebuild better-sqlite3 esbuild` |
| `pnpm install` 第二次报同样错且 "Already up to date" | install 短路，未重跑构建脚本 | 显式 `pnpm rebuild` 解决 |
| Vite 启动后 `Invoke-WebRequest http://127.0.0.1:1420` 连接失败 | Node 17+ 下 Vite 默认绑定的 localhost 解析为 IPv6 `::1`，IPv4 不通 | `vite.config.ts` 设 `server.host='127.0.0.1'`，tauri.conf.json 的 devUrl 同步改 `http://127.0.0.1:1420` |
| 后台 dev 进程 60s 后被杀 | 后台任务默认 timeout=60s | 启动时显式 `timeout: 300` |
