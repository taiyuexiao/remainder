# M21 编辑器全面对齐飞书（版式 / 块手柄 / 大纲 / 操作组）

## 1. 任务背景

用户对编辑器体验仍不满意：格式功能难用、版式与飞书差距大、斜杠菜单 UI 粗糙。先完成调研文档（`docs/research/飞书云文档功能与UI调研.md`），再逐项对照实现。AI 功能（AI 排版/流式纠错/错别字检查/询问/润色）保留。

## 2. 实现清单（对照调研文档第 8 节差距分析）

### 2.1 页面版式（飞书式极简）
- 内容栏居中 760px；标题 32px 粗体无边框输入框，placeholder「请输入标题」
- 元信息行低对比（🏷 标签 / 来源链接 / 保存状态一行小灰字）
- **删除常驻 sticky 格式工具栏** → 右上角浮动操作组（大纲 / ✨AI排版 / 流式纠错 / 错别字检查），格式操作全部交给浮动工具栏 + 斜杠菜单 + 块手柄
- 润色（✒）与表格化（⇥）迁入浮动工具栏（选区操作就该在选区旁边）

### 2.2 块手柄（editor/BlockHandle.tsx，飞书签名交互）
- 悬停块时左侧浮现「+」和「⋮⋮」
- 「+」：下方插入新段落
- 「⋮⋮」点击：块菜单（转换为正文/H1-3/三种列表/引用/代码块、上移、下移、复制、删除）
- 「⋮⋮」**按住拖动移动块**：蓝色指示线实时显示落点，松手 cut+insert
- 实现要点：`posAtCoords` 定位悬停块（仅顶层块）；拖动位置调整时考虑删除后 pos 前移（`ip > fromStart ? ip - nodeSize : ip`）

### 2.3 大纲侧栏（editor/OutlinePanel.tsx）
- 操作组「☰ 大纲」开关；按 1-3 级标题自动生成，缩进显示层级
- 点击 scrollIntoView 跳转；当前块高亮（selectionUpdate 联动）
- 空文档引导文案

### 2.4 斜杠菜单 UI 微调
- 图标块 28px、圆角 7px、行高加大、分组标题 10px 加字距（对齐飞书密度）

### 2.5 斜杠菜单 UI 二次重做（用户截图对比后）
- 差异复盘：上一版是 Notion 风（彩色底块图标 + 紫色选中行 + 行过高），飞书是**无底块纯色线条图标 + 紧凑 32px 行 + 浅灰 hover**
- 重做：图标改纯色线条（文本/H1-3 蓝 #3370ff、列表紫 #7f6bf5、代码绿 #34c07c、分隔线橙 #f79009、表格青 #14b8a6）；行高 32px、13px 常规字重；hover/选中 #f5f6f7；分组改飞书的「基础/常用」结构；细滚动条

## 3. 关键 bug：BubbleMenu 与条件渲染冲突

**症状**：点击「大纲」后 React 整树崩溃（`NotFoundError: insertBefore`），内容全消失。

**根因**：`@tiptap/react` 的 `BubbleMenu` 组件在 React 树内联渲染一个 div，tippy 插件随后**把这个 div 移动到 popper 里**（脱离 React 管理的位置）。当兄弟节点（大纲面板/AI 面板）条件渲染时，React 以"已被移走的 div"作为 insertBefore 参照物 → 崩溃。

**修复**：BubbleMenu 外层套固定槽位 `<div>`，使条件渲染只发生在槽位外的稳定兄弟之间。此坑 M15 就存在，本次新增条件兄弟才暴露。已记入模块文档备查。
