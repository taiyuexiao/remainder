# M10.2-10.3 项目文件夹前端

## 1. 任务背景

M10.1 已把后端切到「项目文件夹」两层模型（projects = main/side/follow，tasks = 子任务 + 平铺 idea，跟进挂项目级）。本功能点完成前端配套：全部任务页重写为「三栏目项目文件夹 + 想法平铺区」，并让其余页面（今日/小组件/日历/跟进/Inbox）与新模型联动。

## 2. 目标

1. 全部任务页：项目文件夹可展开子任务、行内加子任务、三栏目各自新建项目（follow 必填 person+nextFollowDate）、右侧详情编辑项目/子任务；
2. 今日/小组件子任务带 `项目名 ·` 前缀，日历 chip 提示带项目名；跟进页列 follow 型项目；Inbox 转换可挂已有项目；
3. `pnpm --filter desktop build` 0 错误。

## 3. 需求

### M10.2 TasksPage 重写
- 主线/支线/跟进三栏目（COLUMN_ORDER），栏目内项目文件夹行：📁 名称、进度 done_count/total_count、ddl、优先级、逾期红点；follow 型加 @person/下次跟进日/已催 N 次/「再催」按钮；勾选框整体完成项目；点击选中进详情并展开；
- 展开区：子任务行（勾选完成/标题/ddl/优先级，点击进详情）+ 虚线「添加子任务」输入框（回车 POST /api/tasks {projectId, title}）；
- 栏目顶部「+ 新建项目」：名称 + ddl/优先级，follow 栏目追加 person+nextFollowDate 输入；
- 右侧详情：项目 → name/status/priority/ddl/milestone(main)/tags/note/person/nextFollowDate(follow) + 完成/删除（删除 confirm 提示子任务落想法区）；子任务 → title/status/priority/ddl/tags/note + 完成/删除；
- 底部想法区平铺 idea（POST /api/tasks {type:'idea'}），紫色系样式；
- 数据源：GET /api/projects + GET /api/tasks，前端按 project_id 分组（subtasksByProject）。

### M10.3 联动
- TodayPage/WidgetPage：子任务标题前灰色小字 `{project_name} ·`；followUps 段是项目，勾选/单击完成改走 `api.projects.done`（原 doneTask 会 404）；
- CalendarPage：chip title 提示加项目名前缀；
- FollowUpsPage：改列 follow 型项目（api.projects.list({type:'follow'})），next_follow_date 升序、逾期红框、一键再催、行内改下次跟进日（api.updateFollowUp，后端 M10.1 合并逻辑保 person 不丢）、勾选完成项目；
- InboxPage：转换面板选 main/side/follow 时出「所属项目」下拉（该 type 的 active 项目 + 「新建同名项目」）；选已有项目则只传 projectId（转子任务），新建则走旧逻辑；follow + 新建时仍需 person/nextFollowDate。

## 5. 实现方案

- TasksPage 单文件组件化：`TasksPage`（数据加载/选中态）→ `ProjectColumn`（新建表单）→ `ProjectFolder`（文件夹行 + 展开子任务 + 行内添加）→ `IdeaSection`；右侧 `ProjectDetail`/`TaskDetail` 受控草稿 + 保存，选中项用 `key=id` 强制重置草稿；
- client.ts 类型：`FollowTask = Omit<Project,'done_count'|'total_count'> & { title }`（today 视图 followUps 段真实形状），`TodayEntry = Task | FollowTask` 供今日/小组件混排渲染；
- 完成动作按段分流：overdue/today 段 doneTask，followUps 段 projects.done（M10 后 followUps 是项目 id，调任务接口会 404）；
- InboxPage 转换：`convertProjectId === ''` 表示新建同名项目（不传 projectId）；否则只传 projectId，type 由后端从项目继承。

## 6. 遇到的报错及解决方案

| 报错/问题 | 原因 | 解决方案 |
|-----------|------|----------|
| tsc：`Property 'person' does not exist on type 'Task'`（Today/Widget） | client.ts 的 Task 类型未带 person（渲染 followUps 段需要） | Task 加 `person?: string \| null` |
| tsc：`FollowProject[] 不能赋给 Task[]`（缺 project_id） | FollowProject extends Project，无 project_id；而 Section 参数是 Task[] | 引入 `FollowTask`（真实形状）+ `TodayEntry = Task \| FollowTask`，Section 入参放宽 |
| tsc：convertInbox 参数类型 never | `Partial<TaskInput & ProjectInput>` 中 type 字段 `'idea' & ProjectType` 交叉为 never | 独立 `ConvertInput` 接口 |
| 今日/小组件勾选跟进项会 404（存量 bug） | M10 后 followUps 段是项目，原代码调 doneTask | 按段分流到 api.projects.done |
