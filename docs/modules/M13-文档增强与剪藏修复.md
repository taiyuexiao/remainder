# M13 文档模块增强与剪藏修复

## 1. 任务背景

主功能（M1-M12）完成后的一轮体验优化：文档模块缺少拖拽整理能力、文档无法落本地/被 LLM 利用、速记窗缺快捷键、浏览器扩展在部分页面失效。

## 2. 目标

1. 文档树支持鼠标拖拽文档到任意文件夹（含未展开的嵌套文件夹），拖到空白处移回根级
2. 文档可一键导出为本地 Markdown；桌宠聊天（LLM）自动检索知识库文档作为参考
3. 速记窗支持快捷键触发「剪贴板剪藏」（Alt+C）和「存入」（Enter）
4. clipper 扩展在 content script 未注入的页面（扩展重载前的旧标签页等）也能正常工作

## 3. 需求与实现

### 3.1 文档拖拽移动（后改为手动拖拽）
- ~~`DocTreeNode` 加 `draggable` + HTML5 DnD~~：**HTML5 DnD 在普通浏览器实测可用，但在 Tauri WebView2 中 dragover/drop 不稳定，用户侧完全无效 → 改为鼠标自实现拖拽**（同桌宠拖拽模式）
- 新实现：文档行 mousedown → window 监听 mousemove（位移 >6px 进入拖拽态）→ 幽灵框跟随指针 + `elementFromPoint` 判定悬停目标（`data-folder-id` 行 / `data-tree-root` 空白区）→ mouseup 执行 `api.updateDocument(docId, { folderId })`；未位移 = 单击选中
- 跨层级共享状态用模块级单例 `editor/treeDragStore.ts` + `useSyncExternalStore`（避免递归 prop drilling）
- 移动后 `refresh()`（treeKey 递增），展开的节点自动重载子级（复用 M10 的 refreshKey 机制）

### 3.2 文档导出 + LLM 读文档
- server `POST /api/documents/:id/export`：写 `server/data/exports/<标题>.md`（重名自动加序号，含来源/标签/时间元信息 + 正文纯文本），并 `explorer` 打开导出目录
- 编辑器头部加「⬇ 导出到本地」按钮（`api.exportDocument`）
- `/api/llm/chat` 轻量 RAG：用用户消息跑 `searchDocs`（FTS5），命中取 top3 正文片段（600 字）注入 petChat 人格 prompt，注明"相关就参考，不相关就忽略"

### 3.3 速记窗快捷键
- `Alt+C` → 剪贴板剪藏；`Enter` / `Ctrl+Enter` → 存入（原有）；Esc 关闭（原有）
- 按钮和顶栏显示快捷键提示

### 3.4 clipper 扩展加固（v0.1.0 → v0.2.0）
- 四级回退取内容：content script → `chrome.scripting.executeScript` 现场注入（解决扩展重载后旧标签页无 content script 的问题）→ 图片直剪（`info.srcUrl`）→ selectionText 纯文本
- 错误通知区分「没选中内容」/「连不上本地服务（提示双击桌面图标启动）」/「HTTP 错误码」

### 3.5 画布平移
- 画布空白处按住左键拖动 = 平移整个画布（`pan` 状态原已存在但未接事件）；卡片 mousedown 已 stopPropagation，天然不冲突
- 网点背景 backgroundPosition 随 pan 偏移（视差感）；光标 grab/grabbing
- e2e 实测：拖动 (200,100) 后内容层 transform = `translate(200px,100px) scale(1)` ✓

### 3.6 画布卡片：拉伸 + 富文本编辑
- 卡片右下角角标拖拽调整宽高（最小 160×90，本地拖拽 mouseup 保存，复用移动卡片的模式）
- 卡片编辑器从 textarea 升级为 **Tiptap 富文本**：选中文本后可用顶部工具栏设置 字体（宋体/楷体/黑体/等宽）、字号（12-32px）、加粗、倾斜、字体颜色、高亮背景
- 字号用自定义 `FontSizeAttr` 扩展（textStyle 标记上加 fontSize 属性）；内容以 HTML 存储，旧纯文本卡片自动兼容（查看时按类型分支渲染，编辑时转 HTML 段落）
- 保存：失焦 / Ctrl+Enter / ✓完成；Esc 取消；工具栏按钮 onMouseDown preventDefault 保持选区

### 3.7 速记窗：放大 / 拖动 / 拉伸
- 标题栏按住拖动窗口（decorations:false 自实现，复用桌宠拖拽模式）
- 标题栏右侧 🗖/🗗 按钮：默认 520×200 ↔ 放大 760×420 一键切换
- 右下角拉伸柄：拖拽任意调整宽高（最小 420×160）
- 尺寸存 localStorage(`capture-size`)，下次唤出自动恢复

### 3.8 后端启动门（修复重启后"后端连接失败"频发）
- 根因：① bat 用 `pnpm dev:server`（tsx watch）起服务，慢且偶尔静默失败；② 前端打开即请求，后端未就绪直接报错不重试
- bat 改为优先 `node server\dist\index.js` 直接拉起（无 pnpm/tsx 依赖，秒级启动；dist 缺失才回退 pnpm dev:server）
- App.tsx 加就绪门：轮询 `/api/health`（1s × 30 次），就绪前显示"正在连接后端服务…"启动画面，超时可手动重试；就绪后才挂载页面
- e2e：后端挂 → 启动画面 ✓；拉起后端 → 自动进应用无报错 ✓
