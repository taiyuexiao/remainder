# M33 文档切换修复 + 站内文档引用（分享链接）

## 目标

1. 修复：文档栏目中左侧树切换文档时右侧编辑器不更新的 bug
2. 重做分享链接：去掉假网址，改为站内可跳转、可回退的文档引用（类飞书云文档体验）
3. 修复：有序列表空项 Backspace 后卡在列表里、无法回到顶格段落的 bug
4. 代码块：新建默认沿用上次选择的语言（用户高频 java/python/bash）

## 改动

### Bug 修复：文档切换无反应

- 根因：`EditorShell` 把 `docId` prop 复制进内部 state `realId` 后无任何同步，`DocsPage` 渲染 `<EditorShell>` 又没加 `key`，换文档时 React 复用实例、`useEffect([realId])` 不触发、编辑器不重建
- 修复：`desktop/src/pages/DocsPage.tsx` 给 `<EditorShell key={selectedDocId}>`，换文档强制整体重挂载

### 站内文档引用

- 链接格式：`remainder://doc/<docId>`（自定义 scheme，非 http 网址）
- `desktop/src/editor2/docRef.ts`（新增）：`DocRef` 内联 atom 节点（attrs: id/title），渲染为蓝色 📄 标题 卡片；`DOC_REF_RE` 匹配粘贴文本
- `desktop/src/editor2/extensions.ts`：注册 DocRef；`editorPropsForPaste` 新增第二参 `resolveDocTitle`；`handlePaste` 在表格/Markdown 检测前拦截 `remainder://doc/<id>`，取标题后插入 docRef 节点；新增 `handleClick` 点卡片派发 `fe-nav-doc` 事件
- `desktop/src/editor2/EditorPage.tsx`：传入 `(id) => api.getDocument(id).then(d => d.title)`
- `desktop/src/editor2/SharePopover.tsx`：链接改为 `remainder://doc/<docId>` + 使用提示
- `desktop/src/pages/DocsPage.tsx`：监听 `fe-nav-doc` → 压 `docHistory` 栈并切换文档；`goBack` 有历史弹栈回上一篇、无历史回列表；树/文件夹直选清空历史
- `desktop/src/editor2/fe.css`：`.fe-doc-ref` 蓝色胶囊样式（hover 加深 + 下划线）

### Bug 修复：列表空项 Backspace 卡死

- 根因：空列表项（回车生成的空 "2." 项）按 Backspace 走 ProseMirror 默认 joinBackward，把空项并成**上一项内部的第二个段落**（无序号、有缩进），光标陷在 listItem 里，再按 Backspace 只会并入正文，永远出不来
- 修复：`desktop/src/editor2/indent.ts` FeIndent 新增 Backspace 快捷键——光标在空段落开头且该段落是 listItem/taskItem 首个子节点时，`liftListItem` 出列表回顶格段落；其余场景一律返回 false 走默认
- 注：空项按 Enter 退出列表的手势原本就是好的（实测确认），未动

### 代码块默认语言：记住上次选择

- `desktop/src/editor2/CodeBlockView.tsx`：模块级 `lastLang` + localStorage(`fe:code-lang`) 持久化，导出 `defaultCodeLang()`；语言下拉两处选中入口统一走 `setLang()` 记忆
- 坑：
``` + Enter 走的是**父级 CodeBlock 的 input rule**（prosemirror-inputrules 在 Enter 键按下时也会跑规则，正则尾部的 `[\s\n]` 就是为此），优先于扩展键盘快捷键——之前自定义的 Enter 快捷键根本拦不到
- 因此重写 `addInputRules()`（放宽语言字符集到 `[a-zA-Z0-9+#-]+`，无语言时用 `defaultCodeLang()`，显式 ```lang 也计入记忆）
- 各创建入口改传 `{ language: defaultCodeLang() }`：shortcuts.ts(Ctrl+Alt+C)、slashItems.tsx、Toolbar.tsx、TextStyleMenu.tsx；`ai/aiOps.ts` 顺手修正非法语言值 `'plain'` → `'plain text'`
- 插入代码块的快捷键本来就存在：**Ctrl+Alt+C**（对齐飞书 ⌘⌥C）

## 报错及解决方案

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| e2e 点不到树中文档（title=null） | App 主侧边栏也是 `<aside>`（w-52），`querySelector('aside')` 先命中它 | 选择器限定 `aside.w-64`（文档树容器），呼应教训 15 |

## M33c 追加：列表悬挂缩进 / 引用行内化 / 返回恢复滚动位置

### 1. 列表“往后移动”观感（顶层悬挂缩进）

- 说明：输“1. ”变列表后右移是列表排版的固有行为（飞书同样如此）；原 `padding-left: 26px` 观感偏重
- 改动（fe.css）：ol/ul `padding-left: 1.4em`；顶层列表 `.ProseMirror > ul/ol` 加 `margin-left: -0.9em`——序号/圆点挂进左侧留白，正文几乎不右移

### 2. 文档引用卡片行内化

- 根因：粘贴用 `tr.replaceSelectionWith(node)`，其 Slice openStart=0 不会并入当前文本块，卡片被顶成独立块
- 修复（extensions.ts handlePaste）：显式 `deleteSelection + tr.insert(pos, node)` + `TextSelection.near` 把光标落到卡片后——卡片紧跟前文、其后可直接续打正文

### 3. 返回恢复滚动位置

- navBus 新增 `saveDocScroll/takeDocScroll`（docId → `.fe-content` scrollTop）
- DocsPage 在 fe-nav-doc 跳转与 goBack 前保存当前滚动；EditorShell ready 后 rAF 恢复

### 验证（e2e 6/6 PASS）

- 顶层列表负边距生效（marginLeft=-14.4px）
- 文中粘贴链接 → 段落结构 `text,docRef,text`，前后文同行
- 跳转→返回后 scrollTop 恢复（600±50）

### 报错及解决方案

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| 引用卡片独占一行 | `replaceSelectionWith` 的 Slice openStart=0，不并入当前文本块 | 改用 `tr.insert` 行内插入 + `TextSelection.near` 定位光标 |
