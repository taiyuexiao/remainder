# M15 编辑器体验对齐飞书（斜杠菜单 UI / 浮动工具栏 / 表格列宽）

## 1. 任务背景

M14 功能实现后，用户反馈斜杠菜单 UI 粗糙、缺飞书的选中浮动工具栏、表格不能拖拽列宽。对标飞书云文档 UI 逐项照抄。

## 2. 目标

1. 斜杠菜单 UI 与飞书一致：分组小标题 + 彩色图标方块 + 单行标签
2. 选中文本弹出浮动工具栏：层级/字体/字号/加粗/倾斜/颜色/高亮/链接
3. 表格列宽可拖拽调整

## 3. 实现

### 3.1 斜杠菜单重做（editor/slashCommand.ts）
- 条目增加 `group`（文本/列表/插入）与 `iconBg`（彩色图标底色）字段
- 弹层按分组渲染，空分组自动隐藏；键盘选中项 `scrollIntoView`；hover 同步选中态
- CSS：248px 白面板、6px padding、分组标题 11px 灰、图标 26px 圆角方块、悬停/选中 indigo-50

### 3.2 浮动工具栏（editor/FloatToolbar.tsx）
- `@tiptap/react` 的 `BubbleMenu`；shouldShow：仅文本选区（排除 codeBlock/image）
- 控件：层级 select（正文/标题1-3，双向同步当前块状态）、字体、字号、B/I、字体颜色、高亮色 + 取消、🔗（复用 prompt 逻辑）
- 共享样式定义抽至 `editor/textStyle.ts`（FontSizeAttr/FONT_FAMILIES/FONT_SIZES，画布编辑器同源）
- DocsPage 编辑器补装 Highlight/TextStyle/Color/FontFamily/FontSizeAttr 五个扩展

### 3.3 表格列宽
- `Table.configure({ resizable: true })`（Tiptap 内置 columnSizing，列边界出现拖拽手柄）
- CSS：`.column-resize-handle` 指示条、`.selectedCell` 高亮、`.tableWrapper` 横向滚动
