# M5.2 Inbox 列表与一键转任务

## 1. 任务背景
M5.1 全局热键速记窗依赖 Tauri 窗口（待装 VS Build Tools），但 Inbox 的列表管理与转任务逻辑是纯 React，可提前在浏览器落地。速记数据模型已在 M1.3 的 API 中支持。

## 2. 目标
- Inbox 页可快速记录想法（回车即存，可带标签）
- 每条速记可一键转为任务（支线/主线/跟进/想法），转 follow 型时强制填被催人+下次跟进日
- 可删除速记；已转换的速记从列表消失

## 3. 需求
- 顶部输入框 + 标签输入框，回车创建
- 列表显示内容、时间戳、标签
- “转为任务”展开类型选择器与 follow 附加字段
- 删除按钮

## 4. 产出
- `desktop/src/pages/InboxPage.tsx`
- `desktop/src/App.tsx`：接入 Inbox 页

## 5. 实现方案
复用 `api.listInbox/createInbox/deleteInbox/convertInbox`。转换面板内联展开，确认后调用 `/api/inbox/:id/convert`，成功后清空面板并刷新。
