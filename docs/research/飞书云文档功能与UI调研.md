# 飞书云文档 · 功能与 UI 设计调研

> 用途：Remainder 文档编辑器对齐参照（M21）
> 来源：飞书官方帮助中心、产品体验拆解文章、社区分析（2020-2026）

---

## 1. 设计哲学（先理解"为什么长这样"）

1. **极简即效率**：新文档里只有「请输入标题」「请输入正文」和一个加号。没有常驻工具栏——功能全部藏在三个浮动菜单里（「+」「=」「选区浮条」），设置就在光标旁边，移动距离最短
2. **一切皆块（Block）**：标题、段落、列表项、任务、代码块、表格、图片、卡片……每种内容都是块，块是编辑的基本单位（整块选中/移动/折叠/转换）
3. **格式要克制**：官方明确建议"格式不要花哨"——没有字号设置（用标题层级代替），高亮块/彩色少用，避免浮夸没重点
4. **结构即目录**：用 1~9 级标题梳理树状逻辑，左侧目录自动生成；不支持用标题调字号就是为了目录不混乱
5. **Markdown 与快捷键全程可用**：极端情况下可以不用鼠标

## 2. 页面布局

| 区域 | 设计 |
|---|---|
| 内容栏 | 居中，约 750px 宽，大量留白 |
| 标题 | 大字号输入框，placeholder「请输入标题」，无边框感 |
| 正文 | placeholder「请输入正文」 |
| 左侧 | 目录大纲（自动生成，点击跳转，可收起） |
| 顶部 | 无格式工具栏；只有文档名/分享/协作等文档级操作 |

## 3. 三个隐藏菜单（核心交互）

### 3.1 「+」加号菜单（块左侧空白处 / 空块行首）

用途：**新增内容**。可插入：
- 样式（各级标题/列表/引用/代码块/分割线）
- 任务列表（可设负责人、截止时间）
- 图片（拖入/粘贴均可，一行多张）
- 表格 / 电子表格 / 多维表格
- 流程图、思维导图、UML 图、公式
- 链接、@人员、@群名片、@云文档（飞书生态特有）
- 投票、网页卡片（视频/地图等）

### 3.2 「=」块手柄菜单（悬停块左侧的 ⋮⋮ 图标）

用途：**调整整段格式 + 块操作**：
- 转换为：1~9 级标题、正文、有序/无序列表、检查项、引用、代码块、分割线
- 缩进和对齐：增加/减少缩进（也可 Tab / Shift+Tab）
- 评论、复制、删除
- **拖动**：按住 ⋮⋮ 拖动移动块位置；拖动中显示蓝色长线提示落点，左侧浅蓝线段数量表示缩进层级
- **标题折叠**：点击标题左侧三角收起块，收起后黑色三角常亮表示可展开；收起后再拖动可整段调整文档结构

### 3.3 选区浮动工具栏（选中文本弹出）

- 层级（正文/标题）下拉
- 加粗、斜体、下划线、删除线、行内代码
- 字体颜色、背景高亮（可输入 HEX）
- 有序/无序列表、链接、评论
- 「...」展开更多：调整内容布局、插入引用和代码块

## 4. 斜杠菜单（/ 命令）

- 触发：**行首或空格后**输入 `/`；继续输入过滤（支持中文/英文/拼音）
- 键盘 ↑↓ 选择、Enter 执行、Esc 关闭；鼠标点击
- 内容与「+」菜单一致（块类型插入）
- 定位：光标下方，贴近光标

## 5. 块类型清单

标题 1~9 级 / 正文 / 无序列表 / 有序列表 / 任务列表（检查项，可嵌套）/ 引用 / 高亮块（callout，可换底色和表情图标）/ 代码块 / 分割线 / 表格 / 多维表格 / 电子表格 / 图片 / 分栏（布局）/ 目录块 / 流程图 / 思维导图 / UML / 公式 / 投票 / 附件 / 音视频 / 网页卡片 / 同步块 / @人、群、云文档链接

## 6. 目录大纲

- 左侧边栏，按 1~9 级标题自动生成树状目录
- 点击目录项滚动跳转；当前位置高亮
- 可折叠/展开子级

## 7. 其他细节

- 单文档上限 50 万字；标题最多 9 级
- 缩进：Tab / Shift+Tab 作用于整个块；也支持首行缩进（偏好设置）
- Shift+Enter 块内换行（同一块内多段落）
- 图片：粘贴/拖入直接插入；表格：悬停单元格出现行/列操作手柄，列宽可拖拽
- 有序列表序号可点击修改

## 8. Remainder 差距分析（现状 vs 飞书）

| 项 | 飞书 | 我们现状 | 行动 |
|---|---|---|---|
| 页面版式 | 居中 750px、无边框标题、极简 | 有 sticky 格式工具栏 + 标题/标签两行框 | **重做**：居中大标题、隐藏格式工具栏，AI 功能收进右上角轻量操作组 |
| 「+」菜单 | 块左侧加号，内容丰富 | 无（只有斜杠菜单） | 块手柄含"下方插入"入口 |
| 「=」块手柄 | ⋮⋮ 拖动 + 格式转换 + 缩进 + 删除 | **完全没有** | **新增**：块左侧悬停手柄（拖动移动 + 块菜单） |
| 斜杠菜单 UI | 分组、图标块、单行标签 | 已对齐分组样式，但图标/间距/质感有差距 | 微调（更大图标块、行高、选中态） |
| 浮动工具栏 | 层级/样式/颜色/高亮/链接/更多 | M15 已实现同款 | 保留微调 |
| 目录大纲 | 左侧自动生成 | **没有** | **新增**：可开关的大纲侧栏 |
| 标题折叠 | 标题左侧三角收起/展开 | 没有 | backlog（ProseMirror 需装饰层隐藏节点） |
| 任务列表负责人/截止 | 有 | 无 | backlog |
| 字号设置 | 无（用标题层级） | 我们有字号 | 保留（我们的用户要） |
| **AI 功能** | 无 | AI 排版 / 流式纠错 / 错别字检查 / ✨询问 / 润色 | **保留**，收进顶部操作组 |

## 9. 实现顺序

1. 页面版式（居中大标题 + 顶部操作组替换 sticky 工具栏）
2. 斜杠菜单 UI 微调
3. 块手柄（悬停 ⋮⋮：拖动移动 + 块菜单）
4. 目录大纲侧栏
5. backlog：标题折叠、任务列表负责人/截止、分栏、高亮块 callout
