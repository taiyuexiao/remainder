# Remainder 个性化/主题系统调研（不动代码，先存档）

> 2026-09-07 · 需求：自定义背景图 + 透明度调节 + 二游（原神/星铁）级主题风格 + 参考 DeepSeek Harness 插件式个性化
> 结论先行：**Remainder 有一个巨大的现成红利——Tailwind 4 的全部颜色都是 :root CSS 变量**，换主题 = 换一组变量值，不用改任何组件。主题系统可行性极高。

## 1. 业界个性化方案调研

### 1.1 Windows Terminal（背景图+透明度的标杆）

设置项模型（直接可抄）：

| 设置 | 说明 |
|---|---|
| `backgroundImage` | 背景图路径（可选"用桌面壁纸"） |
| `backgroundImageOpacity` | 背景图透明度 0~1 |
| `backgroundImageStretchMode` | 填充模式（fill/fit/stretch/none） |
| `backgroundImageAlignment` | 对齐（九宫格） |
| `opacity` + `useAcrylic` | 窗口级透明度 + 亚克力材质 |
| `unfocusedAppearance` | **失焦时另一套外观**（细节狂魔） |

### 1.2 Fluent Search（效果分级模型）

- 窗口效果五档：None / Transparent / Blur / Acrylic Blur / **Mica**（Win11 桌面壁纸呼应）
- 自定义壁纸 + 桌面壁纸直通；字体族/字体缩放（0.5×~2.5×）；动画总开关 + 分项动画时长
- 关键交互：**所有调整实时预览**

### 1.3 VS Code（主题工程化标杆）

- 双层模型：workbench colors（UI 框架）+ token colors（语法高亮）
- `workbench.colorCustomizations` 支持按主题覆盖 + 通配符（`[Monokai*]`）
- 主题 = 一个 JSON 文件（colors 键值表），可打包成分发插件

### 1.4 DeepSeek Harness 插件生态（用户点名参考）

- `dsh-theme-plugin`：主题工作室——**5 预设 + 完全自定义调色板 + 热切换 + 持久化**
- `dsh-oh-my-theme`：主题 + **全局字体** + 文件树等一体
- `dsh-skins`：皮肤中心，**10 款皮肤、先试穿再应用**（甚至有个 Windows XP 风）
- `dsh-pet`：鲸鱼娘桌宠——随 agent 状态换动画、摸头、喂食加亲密度、改名（我们的蕾米埃尔方向一致，可抄亲密度/状态联动）
- 共性模式：**预设+自定义双层、热切换、试穿、持久化**

### 1.5 其他参考

- Telegram：主题编辑器（每个 UI 元素单独改色 + 导出分享主题文件）
- WeTab/iTab（浏览器起始页）：壁纸库 + 图标/布局自定义

## 2. 二游 UI 主题设计分析

### 2.1 原神（幻想星空欧式）

- **色彩**：白 + 金（#D3BC8E 系）为主调，选中态亮黄+蓝；元素七色（火水风雷草冰岩）做语义色
- **材质**：**毛玻璃**（官方认证的国风/欧式通用过渡材质）、魔法书/纸张承载信息、星空背景轻微动效
- **图形语言**：神之眼星型要素贯穿 LOGO/图标/边框；教堂窗棂式装饰边框；对称扁平图标+翅膀/魔法元素
- **字体**：汉仪文黑（TYPOS 系美术体，宋黑之间）——原神的品牌资产
- **动效**：转场缩放为主，选中态轻量，氪金动效才重

### 2.2 崩坏：星穹铁道（太空歌剧）

- **色彩**：深蓝夜空底 + 金（匹诺康尼蓝金复古都市）；角色主题色做叙事（三月七冰蓝、卡芙卡暗紫、花火暖色 vs 薇塔冷色）
- **字体**：**汉仪旗黑 65 + DIN Medium** 标准组合；单字体策略——**层级全靠字号和颜色区分，不用字重**
- **气质**：中性黑体承载"太空喜剧"的收放自如（宏大不小气、戏谑不轻浮）
- **对我们的启示**：星铁证明"色彩分级 + 单字体"就能撑起高级感——最适合我们这种工具类应用

### 2.3 绝区零（街头潮酷）

- 高对比黑底 + 荧光色（橙/绿）、录像带/涂鸦街头元素、大字报排版
- 我们的桌宠人格就是绝区零的蕾米埃尔——主题可以呼应

## 3. Remainder 落地方案

### 3.1 关键技术发现：Tailwind 4 红利

Remainder 全站用 Tailwind 4，**所有颜色类（indigo-*/slate-* 等）在 v4 都是 `:root` 上的 CSS 变量**（`--color-indigo-600` 等）。
→ **换主题 = 运行时覆盖一组 CSS 变量**，零组件改动。皮肤系统可以纯 CSS 变量包实现。

### 3.2 主题模型设计

```
Theme = {
  name: string
  accent: 一组主色变量（--color-indigo-300~700 → 主题色阶）
  neutral: 一组灰阶变量（--color-slate-* → 主题灰阶，可微偏色）
  background: {
    type: 'none' | 'image' | 'gradient'
    image?: 本地图片（上传存 server/data/assets/）
    opacity: 0~1（默认 0.15，业界甜点 0.1~0.3）
    blur: 0~20px（毛玻璃度，原神材质）
    gradient?: CSS 渐变预设
  }
  font?: 全局 UI 字体覆盖（dsh-oh-my-theme 模式）
  surfaceOpacity?: 面板不透明度（配合背景图让内容可读，Fluent Search 模式）
}
```

- **背景层实现**：App 根部加一个 fixed 背景层（z-index -1），图片+透明度+blur；各页面面板可调 surfaceOpacity 透出背景
- **主题存储**：localStorage（单机）→ 后续可入 settings 表走团队同步
- **交互**（抄 dsh-skins）：设置页「🎨 个性化」区，预设卡片**先试穿再应用**，实时预览

### 3.5 红线（业界教训）

1. **可读性永远优先**：背景图透明度默认 ≤0.3，微软官方 acrylic 文档强调文本对比度必须达标——面板上内容区默认不透或微透
2. **动效要轻**：原神选中态轻量、氪金才重；我们工具类应用全程轻动效
3. **主题不改信息密度**：只换皮，不动布局/间距（飞书对齐成果不能丢）
4. 主题文件用 JSON 可导出——**可以直接用我们的发布/同步机制把主题包发布给团队**（K4 机制的绝佳用例）

## 5. 补充调研：背景图可读性问题（2026-09-07 用户实测反馈）

> 问题：用了背景图后文本看不清。当前实现是「图本身降 opacity + 壳层半透明」——图被冲淡且没有内容保护层。
> 业界有标准答案：**scrim（遮罩层）**。

### 5.1 业界方案对比

| 方案 | 代表 | 机制 | 优劣 |
|---|---|---|---|
| **Scrim 遮罩层**（行业标准答案） | Material Design / WCAG 指南 | 图与文字之间加半透明渐变/纯色层；推荐 30~70%（40% 理想）；MD3 抽屉 scrim = 黑 32% | 最简单最有效，几乎不可察觉；缺点：图会变"闷" |
| **壁纸端处理**（dim/grey/blur） | Muzei（Android 壁纸标杆） | 三滑杆直接处理图本身：模糊 / 变暗(DIM) / 灰度(GREY) | 保留氛围、减少干扰；用户可控 |
| **系统自动压壁纸** | iOS 锁屏/AOD | 壁纸默认模糊或变暗，内容优先（iOS 26 默认 AOD 壁纸模糊化，被用户骂但官方坚持） | 零操作；用户可能嫌"看不到图" |
| **文字区域局部保护** | NN/g 案例 | 只 blur 文字后方区域 / floor fade 底部渐变 / 文字背后半透明盒子（不透明度要 ≥50% 才达标） | 精准但实现复杂 |
| **文字描边/阴影** | WCAG 备选 | text-shadow 必须深色高不透明（rgba(0,0,0,.8)），浅色低透明阴影反而更糟 | 辅助手段，不能独立用 |
| **内容"舞台"化** | Win11 Mica 设计哲学 | 背景只留在边距/留白区，内容区给实心面板 | 最稳但背景存在感弱 |

硬性指标：**WCAG AA 正文 4.5:1、大字 3:1**（文字与"图+遮罩合成后的有效背景"之间）。

### 5.2 我们的架构修正（待实施，先存档）

当前：`背景图(降 opacity) → 壳层半透明(0.82) → 内容`
问题：图被 opacity 冲淡发灰；壳层 82% 白仍让 18% 的图纹理直接贴着文字。

**改为 scrim 模型**：

```
背景图（opacity 100%，保持鲜艳）
  → scrim 层（默认白色 85%，可调 60~95%；深色图可切黑色 scrim）
  → 壳层（恢复不透明或微透）
  → 内容
```

- **透明度旋钮改为控制 scrim 强度**（而不是图本身的 opacity）——图保持鲜艳，可读性由遮罩保证
- **加 Muzei 两件套滑杆**：变暗 dim（0~60%）、灰度 grey（0~100%）——用户图太花时直接处理图
- **scrim 颜色**：浅色图用白 scrim、深色图用黑 scrim（P3 可用 canvas 采样图片平均亮度自动选）
- 默认参数建议：scrim 白 85% / dim 0 / grey 0 / blur 0（背景存在感克制但可读）
