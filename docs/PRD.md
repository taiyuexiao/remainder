# Remainder 产品需求文档（PRD）

> 版本：v1.0 ｜ 状态：待确认 ｜ 最后更新：2026-08-28

## 1. 背景与痛点

作者为程序员，工作中任务多且杂：

- **有大块任务**：时间排期严密的主线项目开发任务
- **有大量支线任务**：零散、需不断推进跟进的事项（项目申请、流程审批等），经常需要**催促他人**
- **核心痛点**：工作太忙，想不起来主动去备忘录类 App 查看 → 忘任务 → 被领导催
- **次痛点 1**：奇思妙想没有顺手的记录入口（手机打字不便、飞书入口太深、微信文件传输助手不便检索与沉淀）
- **次痛点 2**：任务的时间安排分析需要 LLM 能力

**结论**：被动展示的备忘录注定失败，产品必须**主动、常驻、低门槛**。

## 2. 产品定位

个人任务规划与提醒助手。一句话：**在你忘记之前，先一步出现在你眼前。**

市场上无现成产品满足此组合（调研结论：桌面常驻透明组件 + 双视图 + 跟进建模 + 邮件日报 + LLM + 智能文档的交集为空），故自研。

## 3. 产品形态

### 3.1 桌面小组件（核心，常驻）
- Windows 桌面常驻组件：**占据桌面一块区域**，无边框、透明/半透明背景（透明度 60%–100% 可调），内容直接渲染在桌面层
- 显示**今日视图**：
  - 🔴 已逾期任务
  - 🟢 今日到期任务
  - 🟡 今日待跟进事项（该去催的人）
- 交互：单击任务 = 完成/查看；双击组件 = 展开主窗口；右键菜单（透明度/置顶/退出）

### 3.2 主窗口
- 左侧导航：【今日 | 日历 | 全部任务 | 跟进 | Inbox | 文档 | 设置】
- 中间：任务列表；右侧：选中项详情
- **日历视图**：月历 + 每日任务分布 + ddl 高亮（时间序列直观可视化）
- **全部任务**：非日期视图，按主线/支线分组，聚焦"所有要做的事"
- **跟进**（Waiting For）：按下次跟进日期排序，每条显示「被催人 + 已催 N 次」，一键再催

### 3.3 速记窗
- 全局热键（`Ctrl+Shift+Space`）任意界面唤起
- 屏幕居中约 480px 圆角卡片，毛玻璃质感，**简洁但精致**
- 输入 + 可选标签，回车存入 Inbox（自动时间戳），Esc 关闭
- Inbox 条目可一键转为任务或沉淀到文档

### 3.4 Web 端（v1.5）
- 与桌面端**同一套 React 代码**构建，体验一致
- 通过同一 REST API 读写任务，便于在浏览器中编辑

### 3.5 AI 桌宠（v3）
- 桌面 2D 精灵图宠物（Shimeji 式序列帧），状态机驱动（idle/走动/兴奋/催促）
- 作为**提醒的拟人化出口**：任务到点 → 宠物跳到屏幕中央 + 气泡 + 音效
- 支持气泡对话（接 LLM，可问任务/排期）

## 4. 任务模型（任务四型）

| 类型 | 说明 | 关键字段 |
|------|------|----------|
| **主线** | 项目开发任务，大块、排期严密 | 里程碑、ddl、优先级 |
| **支线** | 零散事项 | ddl、优先级 |
| **跟进** | 等他人推进的事项（催办型） | 被催人、下次跟进日期、已催次数 |
| **idea** | 奇思妙想速记 | 标签、时间戳、可转任务/文档 |

跟进型是差异化设计：普通 todo 工具不建模"催人"，本产品让工具**先催你去催别人**，避免被领导催。

### 4.1 项目层级（M10 起）

- **项目文件夹**：主线/支线/跟进三类都是「项目」，项目是组织单元（名称/里程碑/ddl/优先级/备注都挂在项目级）；
- **子任务**：项目下的执行颗粒，类型从项目继承；项目行显示子任务进度 x/y；
- **想法（idea）**：不项目化，平铺展示，可随时转为项目或子任务；
- **跟进挂项目级**：被催人/下次跟进日/已催 N 次都是项目属性，一键再催作用于整个项目；
- **删项目不删子任务**：子任务自动落入想法区（type 变 idea），不丢数据；
- Inbox 转换：可转为新项目（同名），也可作为子任务挂进已有项目。

## 5. 功能清单与分期

### v1（核心可用）
- 桌面小组件：今日视图（逾期/今日到期/今日待跟进）
- 主窗口：任务 CRUD、双视图（日历 + 非日期列表）、任务四型
- 跟进系统：Waiting For 列表、一键再催
- 全局热键速记 + Inbox（可转任务）
- 提醒：组件常显 + Windows 系统通知（到点右下角弹，带开关）

### v1.5（主动触达）
- 邮件日报：每晚 21:00 本地定时，163 SMTP 发「今日已办 + 当前待办汇总」（只发不收）
- LLM（DeepSeek）生成日报自然语言总结
- Web 端入口

### v2（知识沉淀）
- 智能文档（Tiptap 块编辑器，UI 参照飞书云文档）
  - 块清单：标题/正文/待办/有序无序列表/引用/高亮块/代码块/分割线/表格/图片/分栏/目录
  - **Backlog（暂存后续补）**：多维表格、思维笔记、画板、评论、附件管理、飞书其余全量功能
- 周报/总结模板 + LLM 一键生成/润色
- LLM 任务排期分析、idea 自然语言检索

### v3（情感化）
- AI 桌宠 MVP（精灵图 + 状态机）
- 宠物提醒出口（事件→状态→动画）
- 宠物气泡对话
- Backlog：Live2D 升级（注意 license 红线）

## 6. 非目标（明确不做）

- 多人协作、团队功能
- 收邮件 / 邮件解析创建任务
- 语音输入
- 移动端 App
- 强制打断式弹窗（用户明确不要）

## 7. 提醒策略总览

| 渠道 | 时机 | 侵入性 |
|------|------|--------|
| 桌面小组件常显 | 持续 | 低（余光可见） |
| Windows 系统通知 | 任务到点 | 中（可关） |
| 邮件日报 | 每晚 21:00 | 低（批量总结） |
| 桌宠跳出来 | 任务到点（v3） | 中（拟人化） |

## 8. 数据与隐私

- 数据本体存本地 SQLite（个人 PC），无隐私红线（个人使用）
- LLM 调用可配置开关；云同步/多设备方案见 TECH.md 暂存项

## 9. 网页剪藏与知识库（M11，已上线）

### 9.1 双通道剪藏
- **浏览器扩展**（clipper/，MV3，开发者模式加载）：知乎/CSDN/Google 等任意网页选中图文 → 右键「同步到 Remainder」→ 扩展 POST 本地服务 → 解析管线（defuddle 提取正文 → sanitize-html 清洗 → 图片本地化）→ 入剪藏箱
- **微信/任意 App**：选中 → Ctrl+C → `Ctrl+Alt+Space` 唤起速记窗 → 「📋 剪贴板剪藏」→ 读剪贴板 CF_HTML 走同一管线

### 9.2 剪藏箱
剪藏内容先待整理，可预览、一键转知识库文档、删除。图片全部本地化（防失效防防盗链）。

### 9.3 知识库（文档升级）
- 文档增加：来源链接、标签、摘要
- FTS5 全文搜索（trigram 中文分词，<3 字 LIKE 兜底）
- v1 明确不做：双链、目录树、向量检索
