# Remainder Clipper 浏览器扩展

右键同步网页选中内容（含图片）到 Remainder 剪藏箱。

## 加载方法（开发者模式）

1. 打开 Chrome/Edge，地址栏输入 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」→ 选择本目录（`C:\projects\remainder\clipper`）
4. 确保 Remainder 后端在运行（桌面 Remainder.lnk 启动即可）

## 使用

在任意网页（知乎/CSDN/Google 搜索结果等）**选中文字或图片** → 右键 → 「同步到 Remainder」→ 系统通知提示成功 → 打开 Remainder 主窗口「剪藏」页查看。

## 注意

- 微信公众号文章请走剪贴板通道：选中 → Ctrl+C → Ctrl+Alt+Space → 「剪贴板剪藏」
- 服务未启动时会收到失败通知
